# Junicode

Junicode Bold is used for the Sentimeter wordmark, matching the typeface
used by Calcifer Computing (https://www.calcifercomputing.com/).

The unmodified fonts were obtained from:
https://www.calcifercomputing.com/fonts/junicode/TTF/Junicode-Regular.ttf
https://www.calcifercomputing.com/fonts/junicode/TTF/Junicode-Bold.ttf

Upstream: https://github.com/psb1558/Junicode-font
